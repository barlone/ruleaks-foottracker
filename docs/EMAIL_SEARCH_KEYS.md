# Ключи API для «Поиска по Email»

Части отчёта «Поиска по Email», которым нужен ключ: утечки (HIBP, BreachDirectory, Intelligence X), репутация
(EmailRep) и сотрудники домена (Hunter.io). Ключи кладутся в секцию `[email-search]` файла `config.ini`. В браузер
они не уходят. Пустой ключ означает, что часть не собирается: в отчёте она стоит в списке «Не проверялось» с причиной
«нет ключа». Любой ключ можно переопределить переменной окружения, например `FT_EMAIL_SEARCH_HIBP_KEY`.

После правки `config.ini` сервер нужно перезапустить (на проде — `systemctl restart foottracker`).

Условия сервисов проверены на их сайтах 12.11.2026. Цены и лимиты меняются, поэтому перед покупкой стоит свериться
со ссылками ниже.

## Сводка

| Сервис | Ключ в `config.ini` | Бесплатно | Минимальный платный план |
|---|---|---|---|
| Have I Been Pwned | `hibp-key` | нет (API только по подписке) | Core 1: 10 запросов в минуту, $52.68 в год |
| Intelligence X | `intelx-key` + `intelx-url` | да, после регистрации; 50 поисков в сутки | Researcher: €3 000 в год |
| Hunter.io | `hunter-key` | да; 50 кредитов в месяц | Starter: $49 в месяц |
| EmailRep | `emailrep-key` | новые ключи не выдаются | — |
| BreachDirectory (RapidAPI) | `breachdirectory-key` | да; 10 запросов в месяц | Pro: $7.99 в месяц, 1 000 запросов |

## 1. Have I Been Pwned (HIBP)

Даёт список утечек, в которых есть адрес: название, дату, число записей, какие данные утекли.

**Где взять.**

1. Открыть <https://haveibeenpwned.com/API/Key> и войти по адресу почты (HIBP присылает ссылку для входа).
2. В личном кабинете выбрать план. Поиск по адресу (`breachedaccount`) есть во всех планах Core, Pro и High RPM.
   Бесплатный план HIBP — только поиск в браузере, без API.
3. После оплаты ключ показан в кабинете. Записать его в `config.ini`:

   ```ini
   [email-search]
   hibp-key = <ключ>
   ```

**Какой план брать.** Хватит Core 1: 10 запросов в минуту, $4.39 в месяц при оплате за год ($52.68). Один отчёт делает
один запрос к HIBP. Если два пользователя запустят поиск в одну секунду и сработает лимит, сервер один раз
переждёт паузу из ответа HIBP (`Retry-After`) и повторит запрос.

Все планы: <https://haveibeenpwned.com/Subscription>. Документация API: <https://haveibeenpwned.com/API/v3>.

## 2. Intelligence X (IntelX)

Ищет адрес в архиве утечек, дампов, даркнет-ресурсов и вставок вроде Pastebin. В отчёт попадают названия
найденных документов, дата, раздел архива и ссылка на документ на intelx.io. Сам документ открывается на сайте
IntelX, под учётной записью пользователя.

**Где взять.**

1. Зарегистрироваться на <https://intelx.io>.
2. Открыть кабинет, вкладку «Developer»: <https://intelx.io/account?tab=developer>. Там показаны ключ API и адрес
   экземпляра API, к которому этот ключ привязан. Там же видно, сколько поисков осталось на сегодня.
3. Записать оба значения:

   ```ini
   [email-search]
   intelx-key = <ключ>
   intelx-url = https://free.intelx.io
   ```

**Важно про адрес API.** Ключ работает только со своим экземпляром. У бесплатной учётной записи это
`https://free.intelx.io` (значение по умолчанию). После перехода на платный план адрес меняется, обычно на
`https://2.intelx.io`, но правильный адрес всегда указан на вкладке «Developer». Если ключ и адрес не совпадают,
IntelX отвечает отказом, и в отчёте будет ошибка доступа.

**Лимиты бесплатной учётной записи.**

- 50 поисков в сутки (один отчёт тратит один поиск).
- До 200 результатов на раздел архива. Отчёт и так показывает не больше 100.
- До 5 одновременных поисков. Сервер закрывает каждый поиск сразу после чтения результатов, поэтому место
  освобождается.

Кроме регистрации есть план Academia (для учебных заведений, тоже бесплатный) и пробный период на 7 дней.

**Лицензия.** По условиям IntelX встраивание API в коммерческий сервис требует платной лицензии. Сайт работает по
подписке через бота, так что бесплатный ключ формально подходит только для проверки. Для постоянной работы нужен
платный план: Researcher (€3 000 в год, 200 поисков в сутки) или API (€7 000 в год, для встраивания в продукты).

Тарифы: <https://intelx.io/product>. Документация API: <https://help.intelx.io/api/>.

## 3. Hunter.io

Ищет по домену: организация, шаблон адресов сотрудников (`{first}.{last}@…`), известные адреса с именами,
должностями и страницами, где они опубликованы. Запускается только для собственного домена. У Gmail, Mail.ru и других
бесплатных почтовых сервисов «сотрудников» нет, и Hunter для них не вызывается.

**Где взять.**

1. Зарегистрироваться на <https://hunter.io>.
2. Ключ находится в кабинете на странице <https://hunter.io/api-keys>.
3. Записать его:

   ```ini
   [email-search]
   hunter-key = <ключ>
   ```

**Лимиты бесплатного плана.**

- 50 кредитов в месяц. Остаток не переносится на следующий месяц.
- Бесплатный план отдаёт не больше 10 адресов за запрос. Поэтому сервер всегда спрашивает 10 адресов.
- По странице тарифов поиск по домену тратит кредит за каждый найденный адрес. Тогда один отчёт по крупному домену
  может потратить до 10 кредитов, то есть на бесплатном плане хватит примерно на 5 отчётов в месяц. Точный расход
  виден в кабинете Hunter после первых поисков.

Платные планы: Starter $49 в месяц (2 000 кредитов), Growth $149 (10 000), Scale $299 (25 000). При оплате за год
дешевле примерно на 30%.

Тарифы: <https://hunter.io/pricing>. Документация API: <https://hunter.io/api-documentation/v2>.

## 4. EmailRep (Sublime Security)

Даёт репутацию адреса: подозрительный ли он, был ли в утечках и спам-списках, когда впервые и в последний раз
встречался, на каких сайтах есть профили, возраст домена.

**Получить ключ сейчас нельзя.** По документации Sublime Security, новые ключи EmailRep не выдаются. Запросы без
ключа отключены, а уже выданные ключи продолжают работать. Страница заявки `https://emailrep.io/key` 12.11.2026 не
открылась (HTTP 400). Использовать эту часть можно, только если ключ уже был выдан раньше.

Если ключ есть:

```ini
[email-search]
emailrep-key = <ключ>
```

У ключа низкий суточный лимит (точное число зависит от ключа, считается за скользящие 24 часа). При превышении
EmailRep отвечает отказом, и в отчёте будет «превышен лимит».

Без ключа отчёт ничего важного не теряет. SPF, DMARC и возможность подделать письма от домена вычисляются в части
DNS. Возраст домена берётся из RDAP. Утечки — из HIBP и IntelX.

Документация: <https://docs.sublime.security/reference/emailrep-introduction>.

## 5. BreachDirectory (через RapidAPI)

Показывает записи из утечек с адресом: источник, пароль (часто частично скрытый) и его хеши. Отчёт выводит пароли с
предупреждением, как MOSINT.

**Где взять.**

1. Зарегистрироваться на <https://rapidapi.com>.
2. Открыть API BreachDirectory: <https://rapidapi.com/rohan-patra/api/breachdirectory/pricing> и подписаться на план.
3. Ключ RapidAPI (`X-RapidAPI-Key`) виден на вкладке «Endpoints» этого API или в разделе «Apps» кабинета RapidAPI.
   У RapidAPI один ключ на приложение, и он годится для всех API, на которые оно подписано.
4. Записать его:

   ```ini
   [email-search]
   breachdirectory-key = <ключ RapidAPI>
   ```

**Планы на RapidAPI.**

| План | Цена | Запросов в месяц |
|---|---|---|
| Basic | $0 | 10, жёсткий лимит |
| Pro | $7.99 в месяц | 1 000, сверх — $0.10 за запрос |
| Mega | $29.99 в месяц | 50 000, сверх — $0.01 |
| Ultra | $49.99 в месяц | 200 000, сверх — $0.01 |

Цифры взяты из листинга RapidAPI. Официальной страницы BreachDirectory с ними нет, поэтому перед подпиской проверьте их на
вкладке «Pricing». На Pro и выше есть доплата за запросы сверх лимита: если сайтом пользуются активно, следите за
расходом в кабинете RapidAPI.

## Что уходит этим сервисам

Каждому сервису с ключом уходит искомый адрес почты, а Hunter получает только домен. Запросы идут с сервера сайта:
сервис видит его IP-адрес и ваш ключ, но не видит, кто из пользователей ищет. Учтите, что история запросов по ключу
хранится в кабинете сервиса.
