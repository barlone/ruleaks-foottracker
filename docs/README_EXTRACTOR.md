# Извлечение книги «Data Mining» в Markdown по главам

Программа [`extract_pdf_to_markdown.py`](./extract_pdf_to_markdown.py) выполняет автоматическое извлечение текста книги **«Data Mining. Извлечение информации из Facebook, Twitter, LinkedIn, Instagram, GitHub»** (Мэтью Рассел, Михаил Классен) из файла `Data Mining.pdf` в структурированный Markdown по главам.

## Особенности экстрактора

1. **Разбиение по главам на основе оглавления (TOC)**:
   - Документ (466 страниц) автоматически разделен на 18 логических файлов Markdown (`00_` — `17_`).
   - Автоматически сформирован файл-каталог [`markdown_chapters/INDEX.md`](./markdown_chapters/INDEX.md) со ссылками на каждую главу и статистикой по объему слов.
2. **Очистка от типографского шума**:
   - Автоматически удаляются верхние колонтитулы с номерами страниц и названиями глав в теле текста.
   - Сшиваются мягкие переносы строк (`\xad`), разорванные по слогам слова соединяются.
3. **Сохранение синтаксиса и структурных блоков**:
   - Блоки исходного кода на Python (шрифт Consolas) оборачиваются в ```` ```python ... ``` ```` (всего извлечено более 300 блоков кода).
   - Примеры и рисунки оформлены с выделением (`#### Пример X.Y.` и `*Рис. X.Y.*`).
   - Советы и примечания оформлены в виде GitHub Alerts (`> [!TIP]`, `> [!WARNING]`).
   - Списки и сноски форматируются согласно спецификации Markdown.
4. **Высокая скорость**:
   - Все 466 страниц извлекаются и форматируются менее чем за 3 секунды.

---

## Запуск программы

### Стандартный запуск (извлечение по главам):
```bash
python extract_pdf_to_markdown.py
```

### Запуск с объединением всех глав в один общий файл:
```bash
python extract_pdf_to_markdown.py --combine
```

### Параметры командной строки:
- `-i, --input`: путь к PDF файлу (по умолчанию: `Data Mining.pdf`)
- `-o, --output-dir`: папка для сохранения файлов (по умолчанию: `markdown_chapters`)
- `-c, --combine`: дополнительно собрать файл `Data Mining_Full.md` со всей книгой
- `-q, --quiet`: тихий режим
- `--no-frontmatter`: отключить метаданные YAML в начале каждого файла
